
# Habits API — Трекер привычек (ветка main_with_CI-CD)

Backend API сервис для управления привычками, посвященный книге «Атомные привычки» Джеймса Клира
с автоматизированным CI/CD и деплоем на сервер.

Проект представляет собой серверную часть SPA-приложения и реализует REST API
для создания, управления и отслеживания полезных привычек пользователей.

Проект полностью контейнеризирован с использованием Docker.

---

## 📌 О проекте

**Habits API** позволяет:

- создавать, редактировать и удалять привычки;
- разделять привычки на полезные и приятные;
- настраивать периодичность выполнения привычек;
- получать напоминания о привычках через Telegram;
- публиковать привычки в общий доступ.

В данной ветке реализованы:
- контейнеризация проекта;
- CI/CD с использованием GitHub Actions;
- автоматический деплой через Docker Compose.

---

## 🌿 Отличия от ветки `main`

- запуск проекта через Docker Compose;
- автоматическое тестирование и линтинг;
- автоматический деплой на сервер;
- единая команда запуска всех сервисов.

---

## 🧠 Функциональность API

- Регистрация и авторизация пользователей;
- CRUD-операции над привычками;
- Личные и публичные привычки;
- Валидация бизнес-правил;
- Пагинация списков (по 5 привычек на страницу);
- Напоминания через Telegram (Celery + Redis).

## 🚀 Локальный запуск с использованием Docker Compose

1. Клонировать репозиторий:
   ```
   git clone https://github.com/AleksandrG-dot/habits_api.git
   ```
   
2. Создайте файл `.env` по примеру `.env.example`

3. Перейти в директорию проекта:
   ```
   cd habits_api
   ```

4. Запустить проект:
   ```
   docker-compose up --build
   ```

Для создания суперпользователя использовать команду:  
`docker-compose exec web python manage.py createadmin`

## ⚙️ CI/CD и деплой

В проекте настроен CI/CD pipeline с использованием GitHub Actions:
- запуск тестов;
- линтинг кода;
- сборка Docker-образов;
- автоматический деплой на сервер через Docker Compose.

Первичный деплой выполняется вручную, все последующие обновления
происходят автоматически при push изменений в репозиторий.

Подробная инструкция по настройке сервера и процессу деплоя
доступна в документе:

- [`/docs/DEPLOYMENT_GUIDE.md`](docs/DEPLOYMENT_GUIDE.md)
