
## Техническое задание на настройку CI/CD и деплой проекта Habits API

### 1. Общая информация
Документ описывает требования к контейнеризации, автоматизации тестирования и деплоя backend-сервиса.

### 2. Цели автоматизации
- автоматизация тестирования и линтинга;
- упрощение локального запуска проекта;
- автоматический деплой на сервер;
- повышение стабильности окружений.

### 3. Контейнеризация
Проект должен быть контейнеризирован с использованием Docker.

Контейнеры:
- Django;
- PostgreSQL;
- Redis;
- Celery;
- Nginx (при необходимости).

Для каждого сервиса создаётся Dockerfile.

### 4. Docker Compose
- запуск всех сервисов одной командой;
- использование переменных окружения;
- управление жизненным циклом контейнеров.

### 5. CI (GitHub Actions)
Pipeline должен включать:
- запуск тестов;
- линтинг кода;
- проверку сборки Docker-образов.

Pipeline запускается при push и pull request.

### 6. CD (деплой)
- автоматический деплой через Docker Compose;
- подключение к серверу по SSH;
- обновление контейнеров при каждом деплое.

### 7. Требования к серверу
- установлен Docker;
- установлен Docker Compose;
- настроен SSH-доступ.

### 8. Документация
В README.md должны быть описаны:
- запуск проекта локально;
- настройка сервера;
- настройка CI/CD;
- процесс деплоя.

### 9. Требования к Git
- все изменения загружены в GitHub;
- игнорируемые файлы не попадают в репозиторий;
- работа с pull request.

### 10. Результат
- проект запускается одной командой локально;
- проект автоматически деплоится через GitHub Actions;
- CI/CD pipeline выполняется без ошибок.
