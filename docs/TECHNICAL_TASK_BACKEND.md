
## Техническое задание на разработку Backend API сервиса «Трекер привычек»

### 1. Общая информация
**Название проекта:** Habits API (Трекер полезных привычек)  
**Тип приложения:** Backend API для SPA-приложения  

### 2. Назначение сервиса
Сервис предназначен для создания, управления и отслеживания привычек пользователей,
а также для отправки напоминаний о выполнении привычек.

### 3. Функциональные требования
#### 3.1 Пользователи
- Регистрация пользователя
- Авторизация пользователя
- Доступ пользователя только к своим привычкам (CRUD)

#### 3.2 Привычки
Пользователь может:
- создавать, редактировать и удалять привычки;
- просматривать список своих привычек;
- просматривать список публичных привычек других пользователей без возможности редактирования.

### 4. Модель данных «Привычка»
Привычка описывается формулой:  
> Я буду [действие] в [время] в [место]

**Поля модели:**
- пользователь;
- место;
- время;
- действие;
- признак приятной привычки;
- связанная привычка;
- периодичность выполнения (в днях);
- вознаграждение;
- время выполнения (в секундах);
- признак публичности.

### 5. Бизнес-правила и валидаторы
- нельзя указывать одновременно вознаграждение и связанную привычку;
- связанной может быть только приятная привычка;
- у приятной привычки не может быть вознаграждения или связанной привычки;
- время выполнения не более 120 секунд;
- периодичность выполнения — не реже одного раза в 7 дней.

### 6. API и права доступа
- регистрация и авторизация;
- список привычек пользователя (с пагинацией);
- список публичных привычек;
- создание, редактирование и удаление привычек.

**Пагинация:** 5 привычек на страницу.

### 7. Интеграции
- Telegram API для отправки напоминаний;
- Celery для выполнения отложенных задач.

### 8. Безопасность
- настройка CORS;
- использование переменных окружения.

### 9. Документация
- автоматическая генерация документации API;
- ручное описание эндпоинтов при необходимости.

### 10. Требования к качеству
- покрытие тестами не менее 80%;
- соответствие лучшим практикам;
- успешная проверка Flake8;
- размещение проекта в GitHub.
